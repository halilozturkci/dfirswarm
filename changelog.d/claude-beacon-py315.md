### Changed: Python 3.15 is named untested for the pack tools, with the measurements behind it

- `CONTRIBUTING.md` says Python 3.15 is not supported, meaning untested. The deep-nesting run of `beacon_score` (`network-forensics`) that took 300 s on a hosted macOS runner's 3.15 was not reproduced in `python:3.15` (3.15.2, Linux amd64): 1.4 s wall for the nested series, 0.8 s for `window_end`, four runs together 1.5 s, 2.8 s with an unlimited stack; 3.14 was not tried. No cause was found in `beacon_score`, so the tool is unchanged.
- A 1 MiB stack (SIGSEGV, exit 139) is not a 3.15 trait: the same crash is seen on the host's Python 3.12 with `ulimit -s 1024` (`json.loads` of a 100,000-deep array exits 139; `beacon_score` exits -11 with no JSON). A crash without JSON at a tiny stack was there before and is a known limit.
