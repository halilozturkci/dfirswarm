### Changed: the macOS node tests run in two parts, side by side

The macOS `typecheck · node tests` job took 30 to 55 minutes on a hosted runner, and two runs on `main` were cut off by the job limit. The node suites are now two matrix parts, each running `npm test -- --test-shard=I/2` (node's own sharding, which deals the sorted suite files out round-robin); the typecheck runs in the first part only, so nothing costly is done twice, and the Playwright browser is installed in both. The macOS check names change: `macOS · typecheck · node tests` becomes `macOS · typecheck · node tests 1/2`, and `macOS · node tests 2/2` is new; the two shell-suite parts keep their names. `tests/ci-shards.test.ts` now also fails if the node parts are not shards 1..N of one N, if the typecheck is in no part or in two, or if `--test-shard` on the running Node leaves a suite file out or runs one twice. No harness, pack or skill file changes.
