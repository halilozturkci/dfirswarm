### Added: cloud-forensics turns normalised streams into one timeline, with an external sort and a spreadsheet-safe CSV (`cloud_timeline_export`)

A fifth tool in the cloud pack reads the rows `cloud_normalise` writes (or any JSON Lines or JSON array of rows with the canonical field names) and writes `timeline.jsonl`, in UTC order with ties broken by source order (the order of `paths`, then the file, then the record), and `timeline.csv`. The sort is external: sorted runs on disk, merged in passes of at most 64 runs, so memory follows `chunk_rows` and `chunk_bytes` and not the size of the input (1,000,000 rows peaked at under 200 MiB). The final names are put in place only when the whole merge is done; a run that reached its clock, or left something out, publishes `timeline.partial.jsonl` and `.csv`, whose rows are a correct prefix of the order, and a name already taken is never replaced.

- Every row keeps what its producer wrote (source references, duplicate annotations) and gains a `timeline` object with its sequence number, the time it was sorted by and how that time was read, and its file, record and line. Nothing is deduplicated.
- A time is read from `time_utc`, otherwise from `time_raw` by the shared decoder, which refuses a time with no zone: mixed zones are put in one order by their instants to the nanosecond. A row with no usable time goes to `timeline-unknown-time.jsonl` and `.csv`, in source order, with the reason, and is never sorted as if it were at the epoch.
- In the CSV a cell that begins with `=`, `+`, `-`, `@`, a tab or a carriage return, also after white space or an invisible character, gets a single quote in front; the raw value stays in the JSONL.
- Rows that carry a `cloud_normalise` parser label are copied as that tool cleaned them; every other row goes through the shared withholding rules. The tool carries the shared blocks of the other cloud tools byte for byte, declares `secret_output` for `write_values`, has one clock (`time_limit_seconds`, default 420, at most 480) for the read, the sort, the merge and the writes, and on a signal removes every temporary file and run and leaves a partial coverage file and one line of JSON.

Pack: cloud-forensics.
