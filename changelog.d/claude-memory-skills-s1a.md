### Added: five memory skills that need no new tool (`memory-forensics`)

- **Five leaves.** `triage/address-spaces` (container offset against guest physical against process virtual address, the map that translates between them, missing and padded pages, a raw region against a rebuilt executable), `triage/coverage` (unavailable, failed, partial and completed-negative for memory searches; it needs `evidence/coverage`), `symbols/macos` (capture method, Darwin kernel identity, Intel against Apple silicon marked unverified, ISF provenance; it makes no support claim for any macOS version), `timeline/memory` (acquisition, guest-clock, dump-header, saved-state, creation and smeared-range times; it needs `timeline/clocks`) and `processes/kernel-integrity` (module, driver and kernel views, stale objects, unloaded components, smear, symbol errors; no rootkit verdict from a discrepancy alone). Each opens "Use when ... Not for ...", carries Shows, Does not show, Record and Sensitive output, and points to the leaves that hold a rule instead of repeating it. No existing sentence moved.
- **The router names each of the five once.** The pack's index is now 25 entries; the pack is still shown by its router alone when a run's index is over the budget. The README says twenty-five skills.
- Tests: `tests/pack-memory-skills.test.ts` holds each added leaf to the opening, the four headings, the tools that exist, the `needs` rules (no leaf needs both `evidence/coverage` and `timeline/clocks`; each chain stays under the 1,750-token warning), the macOS no-claim rule and the no-verdict rule; each fails on the base (the leaves are missing) and passes on this change.
