### Added: network-forensics: `capture_transform`, derivative captures with their accounting

- **A tool over `editcap`, `mergecap`, `tcpdump -r` and `text2pcap`**, one operation per call: `split` (by packets or seconds), `merge` (chronological, or `-a` appended), `filter` (a recorded BPF filter), `dedup` (a window of packets or seconds), `convert` (`pcap` or `pcapng`) and `hexdump` (a text hex dump to a capture). The original is opened for reading only (size and SHA-256 recorded); every output is a new file under `out_dir`, labelled "derivative, not evidence", and a `text2pcap` result is also labelled synthetic: its timestamps, and its headers when an option asks, were made by `text2pcap`.
- **Every answer accounts for the packets.** `accounting` has `packets_in`, `packets_out`, `dropped`, `dropped_by` and `balanced`, from `capinfos -M` of the inputs and the outputs; a split, a merge and a convert keep every packet, and counts that disagree make the answer `partial`. A filter and a dedup say they drop packets and that the derivative is not the capture. The exact settings, the argument vectors and the version of each program are in the answer. A pcapng converted to pcap lists what the pcap format has no place for.
- **Refusals.** A time shift has no parameter, and a parameter that names one is refused. An input `capinfos` cannot describe as a capture, or that is not a regular file (a FIFO is never waited on), is refused before any program runs. A program that exits nonzero or outlives `max_seconds` places nothing.
- **Placing.** A part is written to a hidden temporary directory inside `out_dir` and placed with `place_without_replacing`: an output never replaces a file that is there (`-2`, `-3`), and a stop leaves no part under a final name. The derivative rows are paged (`limit` inline, the whole in `all_results`).
- **Shared blocks.** The tool carries PROCESS (the general text), PLACE, PAGE and STOP (the windows text). The STOP block comes first in the file so that its handler is in from the start; the PROCESS block, which follows, defines the handler `main()` installs, and the tool's last word removes the temporary directory and the hidden file of a page. The census counts follow: PROCESS general 33, PLACE 46, PAGE windows 38, STOP windows 59, and the byte comparison 76.
- **`capture/derivatives`** names the tool in `tools:` and in its first bullet. The README says seven tools.
- Real `editcap`, `mergecap`, `tcpdump`, `text2pcap` and `capinfos` were not available where this was built: the suite uses stand-in programs, so it proves the wrapper (arguments, accounting, placing, stopping) and nothing about the programs' output formats. One test runs against the real programs when they are installed and says so when they are not.
- Pack raised: `network-forensics` (minor).
- Tests: `tests/pack-network-capture-transform.test.ts` (split, merge, filter, dedup, convert, hexdump, refusals, a bad input, a failing program and unbalanced counts, name collisions with a FIFO, paging with a file-size limit and a full tmpfs, three stop signals, the tool's own clock, the manifest); each fails on the code before this change.
