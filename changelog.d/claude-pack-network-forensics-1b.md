### Changed: the network pack's skills say what each artefact shows and does not show, and stop contradicting the worker prompt

The eight skills are rewritten in the defender's voice as twelve leaves (eight decision-rule leaves and four second-level leaves they point to: `capture/derivatives`, `sessions/objects`, `metadata/fingerprints`, `exfil/counters`), each at most 800 tokens (the largest is about 690), each opening with "Use when ... Not for ...", with its `needs` at most two deep, and each separating what the artefact shows, what it does not show and what to record. `capture/what-you-have` no longer declares a 96-byte capture content-free (minimal Ethernet, IPv4 and TCP headers take 54 bytes: it reads the measured truncation), no longer corrects a clock from one matched event, no longer reads a small file or a short capture as loss or as deliberate removal, and no longer promises flow logs (a flow export is identified and its semantics stated; no flow reader is bundled). `sessions/reconstruct` no longer says "you will not read a TLS payload" (supplied key logs can permit offline decryption of supported TLS and QUIC sessions; a server private key does not open an ephemeral exchange; this pack has no decryption method yet and says so), no longer says a conflicting overlap is evasion, and no longer promises "a hash per object" from Zeek (`hashes_produced` and `hash_fields` say whether any hash exists); it runs every payload-producing command as a job with `secret_output: true`, with the value and its hash kept out of findings. `metadata/dns-tls` separates the ServerHello from the Certificate message (encrypted from TLS 1.3 on), treats a DNS query as no proof of a connection or an action, no longer calls timing "a beacon", and names encrypted DNS, ECH and QUIC as limits; fingerprints and Suricata move to `metadata/fingerprints`, which states no version fact and reads the three fingerprint numbers `suricata_run` returns. `beacons/periodicity`, `exfil/volume` and `correlate/host` no longer turn regularity, outbound asymmetry or a joined clock into a verdict: a series is built before it is scored (SYN observations are not connection starts), `long_final_gap` is not "stopped", every byte counter carries its layer and direction, a staging archive proves no transfer, and a correlation is a chain whose links are labelled observed, inferred or unresolved. `exfil/volume` no longer sends a non-Windows run to a Windows skill. `logs/web-proxy-firewall` is a convenience view of three grammars with a raw timestamp, a derived one and where its zone came from, and carries the credential rule for URLs and raw lines.

`tcpdump` and `text2pcap` are now named by a skill (`capture/derivatives`), `suricata` is declared where `metadata/fingerprints` names it, every skill names the tools and programs its front matter lists and the other way round, and the pack's ten lines leave `tests/pack-links.pending`. The README stops repeating the 96-byte rule, the "connection starts" and "catches a jittered implant" claims and "lossless" for a selected-field listing, and says plainly that no tool reads flow records; the `requires/host.json` `why` lines for `capinfos`, `editcap`, `text2pcap`, `tcpdump`, `tcpflow` and `tcpick` say what each does and does not give. `tests/pack-network-skills.test.ts` holds the size and shape rules and the tool fields the skills name. `evidence/captured-secrets`, TLS key-log decryption, QUIC and HTTP/3, flow records and encrypted DNS are the pack's Phase 2 pull request.

After an independent review the skills follow the corrected tools and lose three errors of their own. `sessions/reconstruct` told the agent to tie a Zeek file to its connection through `conn_uids`, a column Zeek replaced with `uid` and `id` in version 5.1, and to read `hash_fields` as saying whether a hash exists: it now names `uid`, `id.*` and `fuid` and keeps only `hashes_produced` as the signal (a real install has the hash columns whether or not an analyzer filled them); a test holds the Zeek columns the skills name against the columns Zeek has and fails on a dropped one. The content the rewrite had cut from the old skills is back inside the budget (what is worth reconstructing first, and the channels `exfil/volume` listed), `capture/derivatives` has its Sensitive output line, `logs/web-proxy-firewall` no longer needs a capture skill while saying it is not for captures and names the referer column, `beacons/periodicity` says the times are SYN events folded within 120 seconds, `exfil/counters` says `top_talkers` counts the source, `sessions/objects` says a name with a query string is withheld and where the real name is kept, and `metadata/fingerprints` says `home_net` sets HOME_NET and that rules or a config from `inputs/` are refused. The README and `pack.json` stop saying "flow logs" and "beacon detection by timing, exfiltration by volume" and say which tools withhold credentials and by what rule; in `requires/host.json` tcpflow and ngrep carry the licence Homebrew's metadata gives (the apt label is not checked), tcpick's is marked declared and unverified, and a Homebrew route with no formula is gone. The twelve leaves total about 6,700 tokens, the largest about 690. This pull request and the one for the tools merge together.
