### Added: reverse-engineering reads the build information of a Go binary with `go_buildinfo`, executing nothing

The pack had no reader for the header a Go binary carries (`\xff Go buildinf:`) and the module information behind it; `runtimes/go-rust` searched for the marker with `strings`. `go_buildinfo` finds the header in an ELF (its `.go.buildinfo` section, then its writable data segments), a PE (`.data`, then its writable sections) or a Mach-O (`__DATA,__go_buildinfo`, then its `__DATA` segments), thin or in every slice of a universal binary (the first 16), and otherwise by a scan of the file for the magic at an offset that is a multiple of 16 (a copy at another offset is counted and named, not accepted; the scan stops at `max_scan_bytes` and `max_seconds`). It reads both header formats: inline (Go 1.18 and later) and pointer (older), where a virtual address becomes a file offset only through a section or segment the container maps, and a pointer outside them is a named problem. The answer holds the toolchain version, the main package and module, every dependency (path, version, checksum, replacement) and the build settings (`-compiler`, `-ldflags`, `CGO_ENABLED`, `GOOS`, `GOARCH`, `vcs.*`); the first `limit` rows of each table are inline and the whole table is in a mode 0600 JSON Lines file.

`status` is complete only when a header was found and the module block was read from its start sentinel to its end sentinel at the declared length, every line. `found: false` is complete only when every place that can hold a header was looked at, and says that a stripped or older binary may carry none. A cut or malformed block, sentinels the go command does not write, a varint that overflows, a pointer that cannot be followed, a line kind the tool does not read, the 64 MiB or 2,000,000-line cap, the scan budget and the clock each make the answer partial and are named. A file that is not an ELF, PE or Mach-O is `unsupported`; a symbolic link, a pipe or a device is refused.

Every string is withheld by its shape through the pack's shared withholding and one-way-out blocks (copied unchanged), and the value of a build setting whose key is secret-named, and of an `-X` flag whose symbol is secret-named, is withheld whole. A secret of another shape is printed. Measured: 8,400 canaries of 17 shapes in 10 printed slots, none reached an output (at most 0.8% per shape at 95%, Wilson); the canaries are random pieces forced to hold a lower-case letter, a capital and a digit, and strings drawn uniformly at random from a token family's alphabet are printed more often (the manifest gives the rates). A checksum of the exact form `h1:` plus 43 base64 characters and `=`, and a 40- or 64-digit `vcs.revision`, are hashes the go command writes and are shown. `write_values`, in a job run as secret output, writes the whole text of each string the answer withheld to a mode 0600 file, and is refused as JSON before anything is read in any other call. The stop handlers are the windows lineage's shared block, installed at module level.

`runtimes/go-rust` names the tool and says that `found: false` is not "not Go"; the README drops the Go build-information reader from "Not provided" and counts seven tools. Pack `reverse-engineering`.
