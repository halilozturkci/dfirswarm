### Added: reverse-engineering reads a Python bytecode file or marshal stream as data with `marshal_inspect`

The tool library's `marshal_inspect` (a CPython 3.11 to 3.13 marshal stream or `.pyc` read by the tool's own reader, never `marshal.loads`, never a code object built, nothing imported or run) is now also a tool of the pack, and the library copy is the same file, byte for byte. Brought to the pack contract:

- **A pair on every answer.** `status` is complete only when the root object was read to its end, every code object whole, and the whole result is in the file named in `result_file`. A stream that stops (a cut, a count that cannot fit in what is left, nesting past 200, a reference to nothing, an unknown type, a `long` of more than 1,048,576 digits, more than 2,000,000 objects), text or numbers shared so that their copies pass 32 MiB, or the clock (`max_seconds`, default 45) make it partial and are named with the offset; a stream that cannot begin is failed; each is a non-zero exit. `ok` stays, true only for a complete answer.
- **The interpreter is named from the `.pyc` magic number.** A header outside 3.11 to 3.13 (3.14 included, and 3.10 and older) is `unsupported` with the version named; the raw modification time is shown beside the ISO 8601 UTC one.
- **A constant can be a credential.** Every string, name and file name in the answer and in the result file passes through the pack's shared withholding and one-way-out blocks (copied unchanged), with a second look before each string is written; a string over 4,096 characters is given by its length, an integer of 32 digits or more by its size, and a byte string or bytecode is shown as hex only when its text holds nothing the shape rules withhold. A secret of another shape is printed. Measured: 500 canaries of each of 17 shapes planted in a file name, a qualified name, names, string constants and byte-string constants (also as UTF-16), 8,500 in all, one reached an output (the 30-character AWS-secret shape, at most 1.1% for that shape at 95%, Wilson), none of the others (at most 0.8% per shape). `write_values`, in a job run as secret output (`secret_output` is declared for it), writes the whole text of each string and the hex of each byte string withheld to a mode 0600 file under `$OUT`, and is refused as JSON before anything is read in any other call.
- **What the answer holds is bounded.** The root and each field of a code object are cut at a fixed number of nodes (`not_shown` with the count), the first `limit` code objects (at most 5,000) are shown, and the whole is in the result file, a JSON document created exclusively, mode 0600, never replaced by a later call. A symbolic link on the way to `out_dir` is refused, and in a job `out_dir` is under `$OUT`. A symbolic link, a pipe or a device as `path` is refused as JSON. The stop handlers are the windows lineage's shared block, installed at module level.

`runtimes/python-packaged` names the tool and still says that no archive extractor or decompiler is declared; the README counts eight tools. Pack `reverse-engineering`; tool library `marshal_inspect`.
