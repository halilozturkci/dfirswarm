### Changed: reverse-engineering skills name the programs and tools added in Phase C, and say what was never observed

Pack reverse-engineering gains four second-level leaves and changes eight existing leaves; no tool changes. `code/second-readers` describes Ghidra's headless route as a method (a project kept under `$OUT`, the evidence never an extension or a script, no command line given), and names `diec` and `lief`; it says that no tool of the pack runs any of the three and that none was observed on a real sample when it was declared. `managed/decompiled` holds what `clr_inspect` with `decompile` writes and supports, and says that `ilspycmd` was never run for real, that its own requests and the shared libraries of the amd64 build were not measured, and that a process the program leaves running can keep appending to the file after `complete`. `pe/authenticode` holds the reading of `authenticode_verify` (each part `not_checked` without its material, the one osslsigncode release read, `verification` values) and says that whether osslsigncode follows a CRL distribution point by itself was not measured. `documents/second-reading` holds the `second_reading` readings by `qpdf` and `msoffcrypto-tool`: they sit beside the first reading, `qpdf` opens a file with the empty password on its own (`opened_with`), and `msoffcrypto-tool` is passed no password and is asked only whether the file is encrypted.

`code/static-inspection` no longer says the pack declares no decompiler for native code, `packing/static-recovery` no longer says no signature detector is declared (it names `diec`), `elf/structure` and `macho/structure` name the tables and fields the directory tools write, `managed/clr` and `pe/signature-and-resources` point to the new leaves, and `documents/macros` no longer says the second reading may try the empty password (that is `qpdf`'s, for a PDF). The pack README lists what is not provided, and what is declared and never run. `analyzeHeadless`, `java`, `diec`, `qpdf`, `lief` and `msoffcrypto-tool` leave `unreferenced_ok` because a skill names them now. The router and the index list the new leaves; the pack is 1.16.0 with 25 skills, the repository 322.
