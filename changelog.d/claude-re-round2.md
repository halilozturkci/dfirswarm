### Fixed: marshal_inspect reads the clock by what it processes, writes its result under a temporary name, and the static-binary recipe refuses a target it cannot parse in JSON

`marshal_inspect` read the clock every 4,096 objects while one `long` of 1,048,576 digits costs about 0.75 s: a tuple of 100 of them (200 MiB) came back `complete` after 57 s at `max_seconds` 5, and after 64 s at the default 45, past the 60 s of the manifest. The reader now reads the clock each time 64 KiB more of the stream has been taken, before the work on those bytes (and at the start of every `long`), and the views that show the tree read it each 32,768 characters, each byte string, integer or node (which counts for 32) shown, in place of every 1,024 nodes, so that 16,000 strings of 4,096 characters no longer end 8 s past `max_seconds`. The same input is now `partial` at `max_seconds` plus a second or so, with the time limit named. The whole result is written under a temporary name in its directory and given its final name only when complete (a hard link that never replaces a file), so a stop signal leaves neither a half-written file under the result's name nor a temporary one. The tool is version 3, in the pack and in the library.

The `static-binary` recipe read `--target` with `json.loads` and called `.get` on the result: a target of `[` repeated 100,000 times was a RecursionError, and `[]`, `1`, `null` and `"abc"` an AttributeError, each a traceback, exit 1 and no JSON on stdout. It now refuses with a failed document and exit 2, as `capa-floss` does, and so for the JSON it reads back from its programs; its other refusals carry `status` and `status_basis` too (version 1.1.4). The six tools that read their arguments with `json.load(sys.stdin)` (`doc_probe`, `doc_structure`, `entropy_map`, `fuzzy_hash`, `pe_directories`, `pe_info`) named a RecursionError "unexpected failure"; they now say the arguments are not valid JSON, and the refusals of `doc_probe`, `doc_structure` and `pe_directories` carry a `status_basis`.

`go_buildinfo` no longer keeps every offset of an unaligned copy of the magic (a set nothing read: 334 MB for 3 million copies in a 54 MB file); it counts them and names the first eight. `fuzzy_hash` answers a stop by signal with status `interrupted`, as the other tools do (it was `failed`). The manifests of `go_buildinfo` and `marshal_inspect` say what the withholding bound was measured on (canaries whose pieces are forced to hold a lower-case letter, a capital and a digit) and that strings drawn uniformly at random from a token family are printed at about 11% (`sk_live_` keys), 5% (Slack webhook URLs) and 3% (30-character AWS secret keys). The shared withholding block is unchanged. Tools `go_buildinfo` 2, `marshal_inspect` 3, `fuzzy_hash` 8, `doc_probe` 8, `doc_structure` 4, `pe_directories` 3, `entropy_map` 6, `pe_info` 6; recipe `static-binary` 1.1.4.
