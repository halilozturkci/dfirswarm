### Added: one drift test over every shared block, and twins compared file by file

`tests/shared-blocks-census.test.ts` scans `packs/` and `tool-library/` for every BEGIN/END pair in both marker styles (`# BEGIN SHARED X` ... `# END SHARED X`, and the dashed `# ---- BEGIN X ----` ... `# ---- END X ----`, whose trailing dashes differ in length from file to file), groups the copies by family and by the digest of the lines between the markers, and holds them to `tests/shared-blocks.json`, which declares each family's variants with their carrier counts and a one-line reason for every variant beyond the first. At this head there are 18 families and 232 copies. The test fails on a family or a variant that is not declared, on a changed number of carriers, and on a BEGIN without its END; its failure message says how to update the file when a sweep or an adoption adds carriers. Cases inside the test plant an extra variant, an extra family, a removed carrier and a missing END on temporary trees and show each fails. The file declares counts, not digests, so a block that changes in every carrier at once needs no edit. `tests/pack-re-delta10.test.ts` no longer pins "at least 17" carriers of the WITHHOLDING block (the census holds the count, 29 today).

`tests/tool-library-twins.test.ts` now compares every file of both twin directories, at any depth, and fails on a file present on one side only (before, only `run.*` and `manifest.json`); compiled caches are not files of the tool. The two provenance records that marshal_inspect's library copy keeps and its pack does not are declared in `tests/tool-library-twins-allowed.json` (the ceiling is 2). A case plants a helper on the pack's side only and shows it fails.

Recommendation on `LosslessPage`, for the owner (recorded in `tests/shared-blocks.json`, nothing converted): the class is in 67 files in several textual variants, and the largest group, the windows text in the windows pack's tools and their tool-library twins, is one text. Mark that group as a block first (`# BEGIN SHARED LOSSLESS PAGE`), declare it in the census, and leave the other variants unmarked until each pack converges its pager; do not mark all 67 at once, because PAGE and NoReplacePage sit beside it in the same files.
