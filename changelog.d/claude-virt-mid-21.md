### Fixed: virtualization-backup-forensics declares secret_output for write_text in the three manifests

`backup_audit_normalise`, `snapshot_chain_check` and `virtualization_inventory` refuse `write_text` unless they run with `SECRET_OUTPUT=1`, and their skills say to run them as jobs with `secret_output: true`, but no manifest declared it. Each manifest now carries `"secret_output": {"when_args": ["write_text"]}`, so the job service makes a job with `write_text` true secret output by itself (recorded as `secret_output_by: tool_manifest`), whether or not the agent set the flag; a job without `write_text` is an ordinary job. The `write_text` parameter's description says so. The tools' own code is unchanged; their manifest versions rise (backup_audit_normalise 3, snapshot_chain_check 5, virtualization_inventory 3). `tests/pack-virtualization-secret-output.test.ts` asks the job service, tool by tool, with synthetic inputs.
