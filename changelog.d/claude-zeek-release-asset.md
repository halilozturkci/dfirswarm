### Changed: the network pack's Zeek package no longer goes 404 at the next Zeek release

The Zeek project's Debian 12 build service keeps only its latest release, so the pinned `zeek-8.0-core` 8.0.11 packages would have gone 404 at the next Zeek release, as 8.0.10 did on 27 October and broke the `network` and `full` image builds. Pack network-forensics now pins the same two `.deb` files (amd64 and arm64, the same sha256 values) at the assets of the release tagged `assets/zeek-8.0.11` of this repository, which is not the repository's latest release. The release notes name the build service URL each file came from, its sha256 and the licence the pack declares (BSD-3-Clause). The files are a public copy of Zeek's package; the entry keeps `redistributable: false`. `images/README.md` says how to move to a new Zeek version. The weekly pin check (`scripts/check-pins.ts`) watches the two new URLs.
