# The pack's tools themselves use the standard library. TLSH comes from Debian's
# tlsh-tools so arm64 and amd64 images do not compile an unpinned extension.
# The two libraries below are named by the skills that read PE/ELF/Mach-O structure
# (LIEF, code/second-readers) and open protected Office files (msoffcrypto-tool,
# documents/second-reading). msoffcrypto-tool was run for real in the RE-17 container;
# LIEF was never run. They
# are installed from requires/python.lock, which holds them and their dependencies
# with sha256 hashes; the lines here are the notes. Licences are the ones the packages'
# PyPI metadata declare.
lief==1.0.0               # Apache-2.0. Parse and inspect PE, ELF and Mach-O files from Python. Named by code/second-readers; never run.
msoffcrypto-tool==6.0.0   # MIT. Decrypt or test the password of an encrypted Office file. Named by documents/second-reading; run for real in the RE-17 container.
