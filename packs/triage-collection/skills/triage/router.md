Use when the index shows only this line and you need a triage-collection note. Not for rules: each note holds its own.

What was delivered
`identify/collector` naming the collector, its records
`identify/collector-clues` layout clues, no collector named
`identify/collector-records` what each collector's records say
`identify/acquisition-mode` live, mounted, snapshot, earlier
`verify/manifests` custody, baseline, manifest
`verify/target-outcomes` skips, errors, results per target

Reading the delivery
`normalise/inventory` the census, counts, absence
`normalise/layout` source, delivered, analysis path
`normalise/container-members` archive members to files
`normalise/parsers` handing files to platform parsers
`verify/time-layers` four layers of file time
`verify/collector-effects` collector footprint, chronology
`verify/raw-and-derived` collected, parsed, replayed

Bounding an answer
`gaps/what-is-missing` what the delivery can establish
`gaps/coverage-statement` coverage for one question
`coverage/delivered-collection` question coverage from records

Asking for more
`plan/what-to-collect` request through the operator
`plan/sources-windows` Windows sources, by question
`plan/sources-linux` Linux sources, by question
